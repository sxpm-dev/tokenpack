Reading this table

  • Pack fetch+decode — pack download + stream-decode time, charged to this asset only on the FIRST hit per pack (subsequent hits show 0 ms · cached).
  • Baseline asset fetch — time to fetch this single asset over the wire in baseline mode. Adjacent for direct comparison.
  • Extract — pack.extract(file), in-memory, sub-millisecond.
  • Harness IPC tax — total − fetch − extract. Pure overhead from this measurement rig: Playwright page.evaluate CDP roundtrip, base64 encode in browser, base64 decode in Node, base64 re-encode for Fetch.fulfillRequest, and queueing when many requests fire concurrently. Zero in a real Service-Worker deployment.
